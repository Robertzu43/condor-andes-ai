# Presentation and attribution

The public presentation uses Cóndor / Andes Lab as the primary identity and
“Built with OpenAI Decisions API” as secondary attribution. This is an independent
project by Roberto Zúñiga, implemented with Codex; it is not an OpenAI product,
partnership, endorsement or co-branded announcement.

The [official OpenAI design guidelines](https://openai.com/brand/) informed clear
hierarchy, substantial whitespace and restrained typography. The project uses
off-white `#f7f7f5`, near-black `#0d0d0d`, muted gray and neutral borders; teal
remains a project-specific semantic status accent. These are this project's
presentation tokens, not a claim to reproduce an official OpenAI component library.

The live pages use locally available Avenir Next with sans-serif fallbacks. Video
cards render the same locally installed system typeface. No font files are
distributed. OpenAI Sans is described in the official guidelines but is not
bundled here, and no modified or simulated OpenAI wordmark or Blossom is used.

All gameplay in the presentation comes from actual recordings. Result cards
identify their sample size and retain the unfavorable live result. The overview
contains no generated gameplay or fabricated probabilities. Complete traces,
cost accounting, full recordings and edit provenance accompany the preview.
